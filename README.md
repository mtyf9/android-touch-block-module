# Android Touch Block

用于已 root Android 设备的 Magisk 模块。适合触摸屏偶发乱跳、平时通过 scrcpy 操作、偶尔需要在手机上触控输入的场景。开机默认屏蔽选定的物理触摸屏。

## 临时恢复触摸

在 5 秒内依次短按并松开 **电源 → 音量加 → 音量减**，每次按住少于 0.7 秒。模块唤醒屏幕，开放触摸，在锁屏或已解锁界面短暂显示「触摸已临时恢复 30 秒，按电源键可提前结束」；再按一次电源键可提前结束。期间面板原有的漂移和误触仍可能出现。锁屏 PIN 仍由锁屏组件验证。

## 安装

1. 在电脑准备 Python 3.8+ 和 PATH 中的 adb，连接并授权要配置的手机。安装需要 Magisk，并允许 ADB shell 使用 su。先确认可以通过已授权的 ADB 或 USB 鼠标操作手机，以便恢复。
2. 在仓库目录运行 `python prepare.py`（Linux 和 macOS 可用 `python3`）。脚本读取这台设备的输入能力。若有多个候选，请根据名称和物理路径选择内置触摸面板及三个实体键的来源。同一设备可以承担多个键。如果分不清候选，可以在 `adb shell su -c getevent` 中观察单次按键对应哪个 event 节点，再回来选择。多台手机同时连接时，用 `--serial` 指定设备。
3. 将生成的 `AndroidTouchBlock-local.zip` 复制到**同一台手机**，在 Magisk 的模块页面选择从本地安装，然后重启。脚本保留手机当前系统输入排除表的已有条目，并加入选定面板。更换手机或屏幕后应重新生成安装包。
4. 重启后先验证默认屏蔽，再测试组合键、实际滑动和自动重新屏蔽。要恢复长期触摸，在 Magisk 中禁用本模块并重启。已有 1.1 安装沿用相同模块 ID，可覆盖升级。

## 兼容范围

- 预编译程序针对 ARM64。模块需要可读取的 Linux evdev、可写的 /dev/uinput，以及采用 /system/etc/excluded-input-devices.xml 的 Android 输入系统。
- 当前支持一个具有 INPUT_PROP_DIRECT 和 Linux 多点触摸类型 B 能力（slot、tracking ID、X/Y）的面板。虚拟面板按原驱动的轴范围创建。多内屏、折叠屏的显示映射和厂商专用输入路由需要单独适配。
- 电源和音量键可以来自同一节点或不同节点。安装时按能力筛选，运行时按设备名称重新查找，允许 event 编号在重启后变化。设备重名时停止生成。
- 小米 6 是已验证样机：1.1 版已实测实体键组合及触摸，1.2 版在该机验证了能力探测和设备专用安装包生成。其他机型仍需真机验证。

仅查看设备识别结果可运行 `python prepare.py --probe`。监听器源码为 [touch-window.c](touch-window.c)，可用文件首行的 ARM64 交叉编译命令重新构建。
