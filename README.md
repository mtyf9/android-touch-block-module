# 米 6 临时触摸

开机默认屏蔽物理触摸。需要本地输入时，在 5 秒内依次短按并松开 **电源 → 音量加 → 音量减 → 音量加**。每次按键少于 0.7 秒，按键之间松开。系统仍会处理正常的电源键和音量键动作。

完成顺序后，模块唤醒屏幕并临时转发触摸 30 秒。窗口内再按一次电源键可提前结束。该操作只恢复触摸输入；PIN 由锁屏组件验证。原面板的漂移和误触在窗口内也可能出现。

本模块保留系统输入排除表，由 Magisk 的 service.sh 启动 ARM64 监听程序。程序只从 qpnp_pon 和 gpio-keys 两个实体键设备识别顺序。窗口内创建临时直接触摸设备，退出或超时即移除。源码和构建命令见 touch-window.c。
